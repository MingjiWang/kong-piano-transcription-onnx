# Piano Transcription Model (ONNX)

This repository hosts an ONNX export of the piano transcription model from:

Qiuqiang Kong, Bochen Li, Xuchen Song, Yuan Wan, Yuxuan Wang  
**"High-resolution Piano Transcription with Pedals by Regressing Onsets and Offsets Times"**  
arXiv:2010.01815 (2020)

Original weights from Zenodo (CC-BY-4.0):  
https://doi.org/10.5281/zenodo.4034264

The ONNX file is a direct conversion of the official pretrained checkpoint.  
No changes were made to the model parameters.
